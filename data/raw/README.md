# Datos originales

Incluya aquí los archivos originales **solo si su licencia, autorización y tamaño lo permiten**. No cargar datos personales, confidenciales o sensibles.

Si no se pueden distribuir, documente en `docs/02_datos_y_trazabilidad.md` cómo obtenerlos legalmente, nombres, versión, fecha de consulta, transformaciones y, cuando proceda, sumas de verificación.

No invente un dataset y lo presente como réplica del artículo. Si el artículo no publica datos y no es posible reconstruirlos, discuta la limitación con los profesores antes de afirmar reproducibilidad.
